# Collate

基于 [MyGo](https://github.com/egoist/mygo) 的本地 PDF 页面编辑工具。界面与页面处理使用 TypeScript，桌面窗口和原生导出文件选择器使用 Go。功能限定为合并、拆分、删除、旋转、重排、替换。

## 使用

- **合并**：选择或拖入一个或多个 PDF，按添加顺序追加到工作台末尾。
- **拆分**：每行填写一组页码，例如 `1-3, 5`。一组导出为一个 PDF，多组打包为 ZIP；也可选择“每页一份”。只填写一部分页码即可提取需要的页面，工作台保持原样。
- **删除**：选择页面后删除，可批量处理，也可撤销。
- **旋转**：将所选页面顺时针旋转 90°，可连续旋转。
- **重排**：拖动所选页面到目标页前方、使用每页的前后移动按钮，或输入完整页序，例如 `3, 1-2`。多页拖动保持它们原有的相对顺序。
- **替换**：选中目标页面，再选一个来源 PDF，填写来源页码。来源页按输入顺序，与工作台中从前到后的所选页一一对应；两侧页数必须相同。

页码均从 1 开始。拆分、重排中的页码指当前工作台的页序；替换对话框中的页码指来源 PDF。支持逗号（中英文均可）和递增范围，不接受重复页码。

点击页面切换选择状态，按住 Shift 连续选择；可全选。页面修改支持最近 40 次撤销与重做。点击“导出 PDF”保存当前页序和方向，桌面应用使用原生保存窗口，浏览器开发预览使用下载。只有成功导出完整工作台才会标记为“已导出”，拆分导出不改变该状态。

快捷键：`⌘/Ctrl A` 全选，`⌘/Ctrl Z` 撤销，`⌘/Ctrl Shift Z` 重做，`⌘/Ctrl S` 导出，`Delete/Backspace` 删除所选页。

## 范围与限制

- 文件在本机内存中处理，PDF.js 的 worker、字体、CMap 和图像解码资源随应用打包，运行时不依赖 CDN。
- 默认建议导出为新文件；只有在原生保存窗口明确选择原路径时才覆盖文件。保存先写临时文件，写入成功后再替换目标。
- 不包含文字编辑、OCR、批注、压缩、格式转换或加解密。加密、无页和损坏的文件会被拒绝；一次添加多份文件时，全部读取成功后才修改工作台。
- 按页面复制生成新的 PDF，不保留文档级目录、附件或数字签名等结构；现有表单会尽可能扁平化以保留可见内容。重要文件请核对导出结果。
- 工作台和撤销历史不跨应用重启保存。关闭应用前请导出。大文件与较长撤销历史会占用较多内存。

## 开发与验证

依赖 Go（版本见 `go.mod`）与 Bun。在项目根目录执行以下命令；安装时使用已提交的锁文件，避免依赖版本意外变化：

```sh
bun install --frozen-lockfile
bun run dev           # MyGo 桌面开发
bun run dev:web       # 浏览器开发预览
bun run generate      # Go 服务变更后重新生成 src/mygo.ts
bun test              # 六项操作的导出/重读与边界测试
bun run build:web     # TypeScript 检查与前端打包
CGO_ENABLED=0 go test ./...
go run github.com/egoist/mygo/cmd/mygo vet .
bun run build         # 原生应用打包
```

也可用 `bunx mygo build -skip-dmg` 只生成 macOS 应用包。MyGo CLI 与 Go 版本不匹配导致 vet 的 export-data 版本错误时，上述 `go run … vet .` 会用项目 Go 工具链编译同一版本的检查器。

关键文件：`src/pdf.ts` 为页面模型与导出逻辑，`src/main.ts` 为交互和缩略图，`main.go` 为原生保存服务，`vite.config.ts` 负责离线预览资源。生成的 TypeScript 服务绑定保留在 `src/mygo.ts`，不要手动编辑。


## 仓库约定

- 提交 `go.mod`、`go.sum` 和 `bun.lock`，保持 Go 与前端依赖可复现。
- 提交源码、`resources/` 图标、测试，以及生成的 `src/mygo.ts` 服务绑定。修改 Go 服务后运行 `bun run generate`，并一并提交绑定变化。
- `.agents/skills/mygo-maintenance/` 是项目共享的 MyGo 维护规范，随仓库保留。
- `.gitignore` 排除 `node_modules/`、`dist/`、`build/`、`.mygo/`、测试覆盖率、本地缓存、环境变量文件和系统临时文件。环境变量示例可使用 `.env.example`。
- 本地测试 PDF 和导出结果放入 `tmp/`、`exports/` 或系统临时目录，避免将个人文档提交到仓库。必要的脱敏测试样本可以放入测试目录；当前测试在内存中生成 PDF，无需外部样本。
